# Code of Conduct

Sizzle follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be respectful, focus on what's best for the project and the people using
it, and accept constructive feedback gracefully. Harassment, personal attacks and discriminatory
language aren't tolerated anywhere in the project: issues, pull requests, discussions or reviews.

Report unacceptable behaviour privately by emailing [sizzle@mckinnon.dev](mailto:sizzle@mckinnon.dev).
Reports are handled confidentially.
