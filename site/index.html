Sizzle GitHub

Every recipe you love, minus the life story.

Sizzle is a cookbook you run yourself. Share a recipe page from your phone and it keeps the ingredients, the steps and the best photo. The ads, pop-ups and 2,000 words about somebody’s grandmother stay behind.

Install Sizzle View the source

Free and open source under the AGPL. Runs in one small Docker container.

How it works

  1. Share

    On any recipe page, tap Share, then Save to Sizzle. Pasting a link or the recipe text works too, and forwarding recipes by email is coming soon.

  2. Sizzle cleans it up

    Claude reads the page and writes up the recipe: exact quantities, tidy steps, sensible tags. Nothing gets invented, and the junk is dropped.

  3. Cook from your collection

    Browse a fast, photo-first gallery. Search by ingredient, or filter by course, cuisine, diet and time.

Yours, on your own server

Sizzle stores everything in SQLite on your own machine: a home server, a NAS, a Raspberry Pi. There are no accounts, no tracking and no subscription. The only outside service it calls is the Claude API, with your own key.

It’s built to be safe to run at home. Every link it fetches is checked so it can’t be turned against your own network, imported content is never rendered as HTML, and the container runs read-only. 

# three steps, with Docker installed
git clone https://github.com/leemac/sizzle.git && cd sizzle
cp .env.example .env  # add your API key and token
docker compose up -d  # then open http://<your-server>:3000

Built in the open

Sizzle is developed in public as a small software factory: people write the specs, AI coding agents do much of the building, and every change is reviewed by a human before it ships. The issues, the agent playbook and the security model are all on GitHub.
